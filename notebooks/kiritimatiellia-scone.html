Conserved synteny across Kiritimatiellia

Preprint: Oliver, Podell & Allen 2026, bioRxiv Code: KiritimatiallesSCoNe

Kiritimatiellia are a class of Verrucomicrobiota. The few cultured members carry very large sets of carbohydrate-active enzymes and sulfatases, but most families in the class are known only from metagenome-assembled genomes, and their genome organization has not been described.

To compare gene neighborhoods across 898 genomes, I built a new data structure: the similarity-colocalization network (SCoNe). It merges homologous proteins into communities, then links communities that repeatedly sit in the same gene neighborhoods, so conserved synteny shows up as heavy edges. This notebook builds a SCoNe from a synthetic dataset, then shows the networks from the real data.

import sys, itertools, collections, random
random.seed(42)          # igraph draws from Python's RNG: fixes Leiden + layouts
import numpy as np
import pandas as pd
import igraph as ig
import plotly.graph_objects as go
import plotly.express as px
from _common import repo_path, show

REPO = repo_path("KiritimatiallesSCoNe")
sys.path.insert(0, str(REPO))
from scone.scone_metrics import ari, sea, coloc_modularity   # metrics straight from the SCoNe package

How a SCoNe is built

The tool reads the neighborhoods as input rather than inferring them. The same code can therefore work on dbCAN gene clusters, antiSMASH regions, Spacedust synteny blocks, or the genes around one query gene.

Step 1: a sequence similarity network

The synthetic dataset from Figure 2.1 has 712 proteins from 30 planted families, spread across 22 gene clusters. All-vs-all DIAMOND hits with an E-value of 10-10 or lower are kept, and each edge is weighted by -log10(E-value), as in build_ssn_leiden.py.

mock = REPO / "examples" / "mock"
cols = ["q", "s", "pident", "len", "mm", "gap", "qs", "qe", "ss", "se", "evalue", "bits"]
hits = pd.read_csv(mock / "diamond.tsv", sep="\t", names=cols)
hits = hits[(hits.q != hits.s) & (hits.evalue <= 1e-10)].copy()
hits["a"] = hits[["q", "s"]].min(axis=1)
hits["b"] = hits[["q", "s"]].max(axis=1)
edges = (hits.groupby(["a", "b"], as_index=False)["evalue"].min()
             .assign(weight=lambda d: -np.log10(d.evalue.clip(lower=1e-300))))

nodes = pd.read_csv(mock / "nodes.txt", header=None)[0].tolist()
truth = pd.read_csv(mock / "annotations.tsv", sep="\t").set_index("protein_id")["gene"]

g = ig.Graph()
g.add_vertices(nodes)
g.add_edges(list(zip(edges.a, edges.b)))
g.es["weight"] = edges.weight.tolist()
print(f"{g.vcount()} proteins, {g.ecount():,} similarity edges")
712 proteins, 10,645 similarity edges

Step 2: homology communities with weighted Leiden

part = g.community_leiden(objective_function="modularity", weights="weight",
                          resolution=1.0, n_iterations=-1)
leiden = dict(zip(nodes, part.membership))
fam = [truth.get(n, "none") for n in nodes]
print(f"{len(part)} Leiden communities; "
      f"ARI vs. planted families = {ari(part.membership, fam):.3f}")
30 Leiden communities; ARI vs. planted families = 0.907
layout = g.layout_fruchterman_reingold(weights=[np.log1p(w) for w in g.es["weight"]], niter=500, seed=None)
xy = np.array(layout.coords)
ex, ey = [], []
for e in g.es.select(lambda e: e.index % 3 == 0):         # draw every third edge to keep the figure light
    s, t = e.tuple
    ex += [xy[s, 0], xy[t, 0], None]; ey += [xy[s, 1], xy[t, 1], None]
palette = px.colors.qualitative.Dark24 + px.colors.qualitative.Light24
fig = go.Figure()
fig.add_trace(go.Scattergl(x=ex, y=ey, mode="lines", line=dict(width=.4, color="#5a6272"),
                           hoverinfo="skip", showlegend=False))
fig.add_trace(go.Scattergl(
    x=xy[:, 0], y=xy[:, 1], mode="markers",
    marker=dict(size=8, color=[palette[m % len(palette)] for m in part.membership],
                line=dict(width=.3, color="#111")),
    text=[f"{n}<br>planted family: {f}<br>Leiden community {m}" for n, f, m in zip(nodes, fam, part.membership)],
    hoverinfo="text", showlegend=False))
fig.update_layout(height=430, margin=dict(l=10, r=10, t=10, b=10),
                  xaxis=dict(visible=False), yaxis=dict(visible=False))

Step 3: collapse communities and add colocalization edges

Each gene cluster adds 1 to the weight of every pair of communities it contains, counted once per neighborhood. Edge weight is therefore the number of independent neighborhoods in which two homology groups appear together.

cmap = pd.read_csv(mock / "cluster_genome_map.tsv", sep="\t")
comm_size = collections.Counter(part.membership)
co = collections.Counter()
for genes in cmap.genes:
    comms = sorted({leiden[x] for x in genes.split(",") if x in leiden})
    co.update(itertools.combinations(comms, 2))

# label each community by its majority planted family (>= 75%), else auxiliary_N
labels = {}
for c in comm_size:
    members = [truth.get(n, "none") for n in nodes if leiden[n] == c]
    top, k = collections.Counter(members).most_common(1)[0]
    labels[c] = top if k / len(members) >= .75 else f"auxiliary_{c}"

sc = ig.Graph()
sc.add_vertices(sorted(comm_size))
sc.add_edges([(a, b) for a, b in co])
sc.es["weight"] = list(co.values())
print(f"SCoNe: {sc.vcount()} community nodes, {sc.ecount()} colocalization edges "
      f"(max weight {max(co.values())})")
SCoNe: 30 community nodes, 160 colocalization edges (max weight 8)
pos = np.array(sc.layout_kamada_kawai().coords)   # spreads the dense block more evenly than FR
fig = go.Figure()
wmax = max(sc.es["weight"])
for e in sc.es:
    s, t = e.tuple; w = e["weight"]
    fig.add_trace(go.Scatter(x=[pos[s, 0], pos[t, 0]], y=[pos[s, 1], pos[t, 1]], mode="lines",
                             line=dict(width=.5 + 5 * w / wmax, color=f"rgba(140,210,213,{.15 + .75 * w / wmax:.2f})"),
                             hoverinfo="text", text=f"{labels[s]} and {labels[t]}: {w} clusters", showlegend=False))
vids = list(range(sc.vcount()))
fig.add_trace(go.Scatter(
    x=pos[:, 0], y=pos[:, 1], mode="markers+text",
    marker=dict(size=[(12 + 5.25 * np.sqrt(comm_size[v])) / 1.6 for v in vids],
                color=[palette[v % len(palette)] for v in vids], line=dict(width=1, color="#111")),
    text=[labels[v] for v in vids], textposition="top center", textfont=dict(size=10, color="#eaeaea"),
    hovertext=[f"<b>{labels[v]}</b><br>{comm_size[v]} proteins<br>degree {sc.degree(v)}" for v in vids],
    hoverinfo="text", showlegend=False))
fig.update_layout(height=480, margin=dict(l=10, r=10, t=10, b=10),
                  xaxis=dict(visible=False), yaxis=dict(visible=False))
show(fig)

The mock SCoNe. Node size follows community size (12 + 5.25 times the square root of n, as in the tool). Edge width and opacity follow how many gene clusters share the pair. Hover over a node to see its family.

Scoring a SCoNe

scone_metrics.py defines SCoNe Edge Agreement (SEA). It is an adjusted Rand index computed over the colocalization edges rather than over genes, so it only penalizes partition differences that change the network’s wiring. The package also defines colocalization modularity, which measures how well a partition lines up communities with the block structure of the neighborhoods.

coloc_edges = set()
for genes in cmap.genes:
    coloc_edges.update(itertools.combinations(sorted(x for x in genes.split(",") if x), 2))
p_leiden = {n: str(leiden[n]) for n in nodes}
p_truth = {n: truth.get(n, "none") for n in nodes}
p_singletons = {n: n for n in nodes}
pd.DataFrame({
    "Partition": ["Weighted Leiden", "Planted families", "Every protein alone"],
    "SEA vs. planted": [sea(coloc_edges, p_leiden, p_truth), 1.0, sea(coloc_edges, p_singletons, p_truth)],
    "Colocalization modularity": [coloc_modularity(coloc_edges, p) for p in (p_leiden, p_truth, p_singletons)],
}).style.hide(axis="index").format(precision=3)

Planted families 1.000 -0.056

Point size is the number of coding sequences (CDS) in the genome. Host-associated genomes devote the largest share of their genes to CAZymes (median 2.9% of CDS). Sulfatases are mostly an aquatic trait: the median aquatic or sediment genome encodes sulfatases at 0.4% of its CDS, while the median host-associated genome encodes none. Across genomes, CAZyme and sulfatase counts are only weakly correlated (Spearman’s rho = 0.18).

Beyond glycans: hydrogenases, nitrogen fixation, natural products

The same SCoNe approach was applied to genes flanking [FeFe]-hydrogenases, to nif loci, and to aryl-polyene and other biosynthetic gene clusters. The results suggest that sulfated glycan hydrolysis fuels fermentation, hydrogenases balance redox, and surplus carbon supports nitrogen fixation.

Running SCoNe on other data

pip install git+https://github.com/AaronAOliver/KiritimatiallesSCoNe
diamond blastp -q proteins.faa -d db -o hits.tsv --outfmt 6 --max-target-seqs 3000 -e 1e-3
scone run --homology hits.tsv --coloc neighborhoods.tsv --annotations annotations.tsv \
          --evalue 1e-30 --min-cluster-size 3 --min-edge-weight 5 --out-prefix out/run1 --cyjs

neighborhoods.tsv has one row per neighborhood (cluster_id, genome, and a comma-separated list of genes). The output is an interactive HTML SSN and SCoNe, the community table, SVGs, and a .cyjs file for Cytoscape desktop.
